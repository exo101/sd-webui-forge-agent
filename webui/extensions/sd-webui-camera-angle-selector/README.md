# 🎥 相机角度选择器 - Camera Angle Selector

专业的 Stable Diffusion WebUI 多角度提示词可视化选择器插件。

## 功能特性

### 📐 3D 可视化界面
- **交互式操作**：通过 Three.js 渲染的 3D 场景进行直观操作
- **实时预览**：所见即所得的角度调整体验

### 🎛️ 多角度控制
- **方位角**：8 个方位选择（正面、前右四分之三、右侧、后右四分之三、背面、后左四分之三、左侧、前左四分之三）
- **高程角**：4 个高度选择（低角度、平视、仰拍、高角度）
- **距离**：3 种距离选择（特写、中景、远景）

### 🖱️ 拖拽操作
- **红色手柄**：调整方位角（环绕人物旋转）
- **绿色手柄**：调整高程角（上下俯仰）
- **黄色手柄**：调整距离（远近缩放）

### 📝 提示词生成
- **自动生成**：根据选择的角度自动生成对应的英文提示词
- **一键应用**：直接将角度提示词追加到文生图或图生图的提示词输入框

## 快速开始

### 安装
1. 将插件文件夹 `sd-webui-camera-angle-selector` 复制到 WebUI 的 `extensions` 目录
2. 重启 WebUI
3. 在顶部导航栏点击"相机角度选择器"标签

### 基本使用流程

1. **调整角度**
   - 在 3D 界面中拖拽各颜色手柄调整视角
   - 或使用底部控制面板的下拉菜单选择预设角度

2. **生成提示词**
   - 调整好角度后，点击"应用到文生图"或"应用到图生图"按钮
   - 角度提示词会自动追加到对应的提示词输入框

3. **开始生成**
   - 切换到文生图或图生图标签页
   - 确认提示词已添加
   - 开始生成图像

## 提示词示例

| 角度组合 | 生成的提示词 |
|---------|------------|
| 正面 + 平视 + 中景 | `front view eye-level shot medium shot` |
| 前右四分之三 + 低角度 + 特写 | `front-right three-quarter view low-angle shot close-up` |
| 右侧 + 仰拍 + 远景 | `right side view low-angle shot long shot` |
| 背面 + 高角度 + 中景 | `back view high-angle shot medium shot` |

## 技术实现

### 3D 渲染
- 使用 Three.js 库创建 3D 场景
- 包含相机模型、地面参考网格
- 支持多手柄拖拽交互

### 通信机制
- iframe 方式加载 3D 界面
- postMessage 实现父子窗口通信
- 异步消息处理确保数据传输可靠

## 系统要求

- Stable Diffusion WebUI / Forge
- 现代浏览器（支持 WebGL）
- Gradio
