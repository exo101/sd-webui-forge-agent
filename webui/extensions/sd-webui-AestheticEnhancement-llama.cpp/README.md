# 🎨 美学提升插件 (Aesthetic Enhancement)

**全面的视觉参考 + AI 智能分析工具** — 构图技巧、打光技巧、画师百科，配合本地多模态大模型进行图像分析，提升 AI 绘画作品的美学品质。

Bilibili: https://space.bilibili.com/403361177

## 📖 插件介绍

美学提升插件是一个为 AI 绘画创作者设计的综合视觉参考 + 智能分析工具。

**核心设计理念**：先参考（构图/打光/画师风格），再创作（AI 分析已有作品以获取灵感）。

### ✨ 核心功能

- **📐 构图技巧**: 12 种经典构图示例（S 型、三角形、九宫格、对角线等）
- **💡 打光技巧**: 11 种专业光位演示（伦勃朗光、丁达尔光、逆光、侧顺光等）
- **🎨 画师百科**: 多风格知名画师作品和风格特点介绍
  - 支持点击图片全屏放大查看
  - 画师名称和介绍支持一键复制
  - 按风格分类浏览
- **🎬 AI 智能分析**: 本地多模态大模型分析
  - 支持 **Ollama** 和 **llama.cpp** 双后端
  - 支持图片分析和视频关键帧分析
  - 自动识别构图、灯光、分镜、色彩等元素
- **🔍 点击放大**: 画廊卡片支持全屏查看高清细节
- **📱 响应式设计**: 适配桌面和移动设备
- **🎯 深色主题**: 优雅的深色界面，减少视觉疲劳

### 🎯 适用场景

- AI 绘画提示词参考（构图 / 打光 / 画师风格）
- 摄影构图学习与分镜设计
- 灯光布置灵感
- 美术基础训练
- 画师风格研究与模仿

## 🎬 AI 智能分析（可选功能）

> **注意**: 此功能需要额外配置本地多模态大模型后端，有两种选择：**Ollama**（简单易用）或 **llama.cpp**（性能更高，支持更多模型格式）。

### 两种后端对比

| 特性 | Ollama | llama.cpp |
|------|--------|-----------|
| 安装难度 | 一键安装 | 需要手动配置 |
| 模型格式 | `.gguf`（内部） | `.gguf`（直接加载） |
| GPU 加速 | 自动 | 需手动开启 `--n-gpu-layers` |
| 支持的模型 | Ollama 官方模型库 | 任意 GGUF 格式模型（Qwen3-VL、Qwen2.5-VL、LLaVA 等） |
| 视觉模型启动 | `ollama run qwen3.5:4b` | `llama-server --model xxx.gguf --mmproj xxx.gguf` |

### 前置要求

**Python 依赖**（已随 WebUI 启动自动安装的无需重复安装）：

```bash
pip install requests opencv-python
```

### 方式一：使用 Ollama（推荐新手）

1. **安装 Ollama**: 从 https://ollama.com 下载并安装
2. **下载视觉模型**: 运行以下任一命令：
   ```bash
   ollama run qwen3.5:4b      # 推荐，平衡速度与质量，8GB 显存可用
   ollama run qwen3.5:2b      # 速度最快，4GB 显存可用
   ollama run qwen3.5:9b      # 质量最高，12GB+ 显存
   ```
3. **启动 Ollama 服务**: 安装后默认在后台运行（监听 `http://localhost:11434`）

### 方式二：使用 llama.cpp（推荐高级用户）

1. **下载 llama.cpp**: 从 https://github.com/ggerganov/llama.cpp/releases 下载对应平台版本
2. **下载视觉模型**: 从 ModelScope / HuggingFace 下载 GGUF 格式模型：
   - **推荐**: Qwen3-VL 系列（`Qwen3-VL-4B-Instruct.gguf` + `mmproj.gguf`）
   - 次选: Qwen2.5-VL 系列、LLaVA-v1.6 系列
3. **启动 llama.cpp 服务器**（视觉模型需要主模型 + mmproj 投影文件）：
   ```bash
   # 视觉模型（支持图片分析）
   llama-server --model Qwen3-VL-4B-Instruct.gguf --mmproj mmproj.gguf --host 0.0.0.0 --port 8080 --n-gpu-layers -1

   # 纯语言模型（仅文本分析，不支持图片）
   llama-server --model Qwen3.5-4B.gguf --host 0.0.0.0 --port 8080 --n-gpu-layers -1
   ```
   - `--model`: 主模型文件路径
   - `--mmproj`: 多模态投影文件路径（视觉模型必需）
   - `--host 0.0.0.0`: 允许局域网访问
   - `--port 8080`: 监听端口
   - `--n-gpu-layers -1`: 全部层使用 GPU 加速（CUDA / Metal / Vulkan 需提前编译启用）

### 使用步骤

1. 切换到 **🎬 AI 智能分析** 标签页
2. **选择后端**：点击顶部单选框选择 `🦙 Ollama` 或 `🦄 llama.cpp`
3. **测试连接**：点击对应的 `🔌 测试连接` 按钮
   - 显示 `✅ 连接成功` 表示服务正常
   - 显示 `❌ 无法连接` 请检查后端服务是否启动、地址/端口是否正确
4. **刷新模型列表**：点击 `🔄 刷新模型列表`，如果后端正常运行，会自动列出已加载的模型
5. **选择分析模式**：
   - 🖼️ 图片分析：上传单张图片进行分析
   - 🎬 视频分析：上传视频，自动提取关键帧并批量分析
6. **选择分析类型**：
   - 🔍 综合分析（推荐）: 构图 + 灯光 + 分镜 + 色彩
   - 📐 仅构图分析: 专注识别构图法则和元素分布
   - 💡 仅灯光分析: 专注识别光位和光影效果
   - 🎥 仅分镜分析: 专注识别景别、镜头角度和镜头语言
7. **上传图片/视频** 后点击 `🚀 开始分析`

### 分析结果示例

```
📊 综合分析结果

【构图】
- 主要构图方式：三分法 + 引导线
- 主体位置：画面右侧 1/3 处，符合视觉兴趣点
- 空间层次：前景人物 + 中景建筑 + 远景天空，纵深感强烈

【灯光】
- 主光位置：侧逆光（左上）
- 光位类型：侧逆光 + 补光
- 光影对比：明暗过渡自然，边缘光勾勒轮廓
- 特殊光效：有明显的丁达尔光/体积光效果

【色彩情绪】
- 主色调：暖色调（橙黄 + 深蓝），冷暖对比强烈
- 饱和度：中高饱和度，氛围浓郁
- 情感表达：温暖、怀旧、戏剧性

【改进建议】
- 可尝试降低前景饱和度，增强主体突出
- 画面底部略空，可增加前景元素增强层次
```

### 使用技巧

1. **提示词参考**：
   - 构图：`rule of thirds composition`, `symmetrical composition`, `S-curve composition`
   - 灯光：`rembrandt lighting`, `volumetric lighting`, `cinematic backlight`
   - 画师风格：`by [画师名] style`

2. **对比学习**：将 AI 分析结果与你自己的观察对比，逐步培养视觉敏感度。

3. **视频分析**：视频抽帧间隔建议 30-60 帧（根据视频长度调整），长视频可适当增大间隔避免分析过慢。

## ❓ 常见问题

### Q: 图片无法加载或显示占位图？

A: 请检查：
1. 确认 `Aesthetic-Enhancement` 目录存在于插件文件夹中
2. 确认目录下有对应的素材子目录和图片文件
3. 刷新页面（Ctrl+F5 强制刷新）

### Q: 点击卡片没有反应 / 放大功能不生效？

A: 可能是 JavaScript 未正确加载，尝试：
1. 刷新浏览器页面（Ctrl+F5 强制刷新）
2. 清除浏览器缓存
3. 检查浏览器控制台是否有报错（F12 打开开发者工具）

### Q: AI 智能分析标签页没有显示？

A: AI 分析功能需要以下条件：
1. `scripts/qwen_analysis_ui.py` 文件存在
2. `requests` 库已安装（WebUI 一般已自带）
3. WebUI 启动时无模块导入错误（查看启动日志）

### Q: llama.cpp 无法刷新模型列表 / 测试连接失败？

A: 请检查：
1. llama-server 是否正在运行
2. 端口是否为 8080（可根据实际修改输入框中的地址）
3. 视觉模型是否同时加载了 `--model` 和 `--mmproj`
4. 服务器地址格式：`http://localhost:8080`（不要遗漏 `http://`）
5. 启动命令示例：
   ```bash
   llama-server --model Qwen3-VL-4B-Instruct.gguf --mmproj mmproj.gguf --host 0.0.0.0 --port 8080 --n-gpu-layers -1
   ```

### Q: llama.cpp 提示 "image input is not supported"？

A: 你加载的是纯语言模型，不支持图片输入。请使用视觉模型：
- 需要同时指定 `--model`（主模型）和 `--mmproj`（视觉投影文件）
- 推荐模型：Qwen3-VL 系列、Qwen2.5-VL 系列、LLaVA-v1.6 系列

### Q: Ollama 连接成功但无法进行图片分析？

A: 请确保你下载的是视觉模型（支持 vision 的 qwen 系列）：
```bash
ollama show qwen3.5:4b    # 查看模型信息
ollama pull qwen3.5:4b    # 下载/更新模型
```

### Q: 报错 `TypeError: save_pil_to_file() got an unexpected keyword argument 'name'`？

A: 这是 WebUI 核心文件 `ui_tempdir.py` 与新版 Gradio 的兼容性问题，已修复：
- 在 `save_pil_to_file` 函数签名中增加 `**kwargs` 即可兼容
- 修复后无需重启 WebUI 以外的其他操作

### Q: 如何添加自定义素材？

A: 直接将你的参考图片放入对应目录：
- 构图图片放入 `Aesthetic-Enhancement/构图技巧/`
- 打光图片放入 `Aesthetic-Enhancement/打光技巧/`
- 画师素材放入 `Aesthetic-Enhancement/画师百科/[风格]/`
  - 图片文件：`[画师名].jpg` 或 `.png`、`.webp`
  - 说明文件：`[画师名].txt`（中文介绍，建议 20-200 字）

### Q: 如何贡献新的画师素材？

A: 欢迎贡献！请按照以下格式组织素材：
1. 在 `Aesthetic-Enhancement/画师百科/` 下创建风格子目录
2. 为每个画师添加：
   - 一张代表作品图片（建议 800x1200 像素，JPG/PNG/WebP）
   - 一个 TXT 文件，包含风格特点介绍（中文）
3. 提交 Pull Request 或联系开发者
