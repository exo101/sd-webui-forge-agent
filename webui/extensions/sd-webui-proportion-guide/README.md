# SD WebUI 人体头身比例参考线插件

## 简介

本插件为 Stable Diffusion WebUI 提供了**人体头身比例参考线生成**功能。支持两种工作流：

- **AI 视觉分析流**：连接 llama.cpp 调用视觉模型，分析参考图自动提取身材比例和风格关键词（可自由编辑），然后生成参考图 + Prompt
- **内置风格流**：直接选择头身比和内置风格模板，快速生成参考图 + Prompt

## 功能特性

### AI 视觉分析（llama.cpp 接入）
- 连接本地 llama.cpp 服务，调用视觉模型分析角色参考图
- 自动提取 **头身比/身材描述**、**正向风格关键词**、**负向风格关键词**
- 三个关键词框**均可自由编辑**，用户可对结果进行微调
- 支持任何兼容 OpenAI API 格式的视觉模型（LLaVA、Qwen-VL、InternVL 等）

### 头身比例控制
- **8 档头身比例选择**：2 头身（Q 版极小）到 9 头身（超模大长腿）
- **三种方向布局**：竖直全身 / 竖直半身高腰 / 水平全身
- **网格分隔线**：清晰显示每个头身单位的划分
- **人体轮廓绘制**：显示头部、躯干、手臂、腿部的简化轮廓
- **可调节尺寸**：支持自定义参考图宽度（256-1024px）
- **ControlNet 兼容**：生成的参考图可直接用于 ControlNet 草图/线稿控制

### 内置风格（备用）
- **11 种身材风格**：内置预设关键词，未使用 AI 分析时作为备选
- **正向/负向双输出**：自动组合头身比 + 风格关键词

## 前置要求

使用 AI 视觉分析功能需要：

1. 安装 llama.cpp 并启动一个视觉模型服务（如 LLaVA、Qwen-VL、InternVL 等）
2. 确保服务运行在可访问的地址（默认 `http://localhost:8081`）
3. Python 环境已安装 `requests` 库（如未安装：`pip install requests`）

启动 llama.cpp 示例：
```bash
# 下载视觉模型（如 LLaVA）
./llama-cli --hf-repo llava-hf/llava-v1.6-mistral-7b-hf -p "" --no-display-prompt

# 启动 API 服务
./llama-server -m path/to/vision-model.gguf --port 8080
```

## 安装

### 方法一：通过 WebUI 扩展市场安装（如支持）

1. 打开 Stable Diffusion WebUI
2. 进入 Extensions 选项卡 → Available
3. 搜索 "Proportion Guide" 或 "头身比例"
4. 点击 Install

### 方法二：手动安装

1. 进入 Stable Diffusion WebUI 的 `extensions` 目录
2. 克隆本仓库或复制脚本文件：
   ```bash
   cd extensions
   git clone https://github.com/your-username/sd-webui-proportion-guide.git
   ```
   或者手动创建目录 `sd-webui-proportion-guide/scripts/` 并将 `proportion_guide.py` 放入其中。

3. 重启 WebUI

## 使用方法

在 WebUI 的 txt2img 或 img2img 页面中，找到 **✨ 人体头身比例参考线** 折叠面板。

### 流程一：AI 视觉分析

| 步骤 | 操作 |
|------|------|
| ① | 确认 llama.cpp 服务地址（默认 `http://localhost:8081`） |
| ② | 上传一张角色参考图（最好为全身图） |
| ③ | 点击 **「分析图片」** |
| ④ | 等待视觉模型返回结果，自动填入三个关键词框 |
| ⑤ | **自由编辑**关键词框内容，调整到满意为止 |

### 流程二：生成比例参考图

| 步骤 | 操作 |
|------|------|
| ① | 选择目标头身比例（控制网格线划分） |
| ② | 勾选「使用AI分析结果」使用流程一提取的关键词；或取消勾选，选择内置风格 |
| ③ | 选择方向布局、网格/轮廓显示、参考图宽度 |
| ④ | 点击 **「生成参考图」** |
| ⑤ | 将参考图保存或发送到 ControlNet |
| ⑥ | 把「正向Prompt」复制到正向提示词，「负向Prompt」复制到负向提示词 |

## 注意事项

- AI 分析功能需要本地运行 llama.cpp 视觉模型服务，确保服务地址正确
- 身材比例控制效果对不同的模型表现不同，建议配合 **Klein** 与 **Krea2** 等模型使用以获得最佳效果
- 生成的参考图可用作 **ControlNet** 的草图/线稿输入，帮助稳定生成结果
- AI 分析提取的关键词均为英文，可自由编辑修改
- 未勾选"使用AI分析结果"时，会回退到内置风格模板

## 适用场景

- 角色设计时精确控制身材比例和体型风格
- 需要特定头身比的插画/漫画创作（Q 版、美型、写实等）
- 参考已有角色图，用 AI 提取其身材比例和风格关键词
- 使用 ControlNet 时的参考骨架图
- 批量生成统一比例/风格的角色图
