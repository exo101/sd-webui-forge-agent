
# Regional Prompter Neo (区域提示词)

## 概述

Regional Prompter Neo 是一个专为 SD WebUI Forge Neo 优化的区域提示词插件。它允许你将画布划分为多个区域，并为每个区域分别指定不同的提示词，实现精细的图像构图控制。

## 核心功能

### 1. 区域划分
- **行/列分割**：使用 `ADDROW` 和 `ADDCOL` 关键字将画布划分为行和列组成的网格
- **灵活比例**：通过 `BREAK` 关键字指定每个区域的大小比例
- **视觉编辑器**：内置可视化编辑器，拖拽绘制区域，实时预览

### 2. 提示词分配

基本语法示例：
```
一个女孩, 微笑 -- 默认提示词（基础区域）
BREAK
一个男孩, 严肃 -- 第 1 个区域
BREAK
一只猫, 可爱 -- 第 2 个区域
```

使用 `ADDROW` / `ADDCOL` 进行二维分割：
```
一个女孩, 微笑 -- 所有区域共享的公共提示
ADDROW
一个男孩, 严肃 -- 第 1 行
BREAK
一只猫, 可爱 -- 第 2 行
```

### 3. 区域类型

| 关键字 | 说明 |
|--------|------|
| `BREAK` | 分隔同一行中的不同区域 |
| `ADDROW` | 添加新行 |
| `ADDCOL` | 添加新列 |
| `ADDBASE` | 标记基础提示词，独立于区域控制 |
| `ADDCOMM` | 标记公共提示词，适用于所有区域 |
| `ADDP` | 添加额外提示词 |

### 4. 两种计算模式

- **Attention 模式（默认）**：通过修改注意力机制实现区域控制，效果更精准
- **Latent 模式**：通过潜空间掩码实现区域控制，适合复杂构图

### 5. 高级选项

- **基础提示词权重**：控制基础提示词对每个区域的影响程度
- **公共提示词**：设置所有区域共享的提示词
- **权重分布**：支持线性/对数/指数等多种权重衰减模式
- **高清修复兼容**：支持在高清修复阶段保持区域控制

## 使用方法

1. 在文生图或图生图界面中，展开"场景编辑器 (Regional Prompter)"折叠面板
2. 勾选"启用"复选框
3. 使用视觉编辑器绘制区域，或在提示词中使用 `BREAK` / `ADDROW` / `ADDCOL` 关键字
4. 调整权重、模式等参数
5. 点击生成

## 视觉编辑器

内置的视觉编辑器提供了直观的界面：
- 画笔工具绘制区域
- 橡皮擦修改区域
- 颜色标记不同区域
- 实时预览区域划分效果
- 自动生成对应的提示词格式

## 适用场景

- 多角色构图（每个人物使用不同提示词）
- 前景/背景分离（前景和背景使用不同风格）
- 复杂场景布局（天空、地面、人物分别控制）
- 风格混合（不同区域使用不同风格）
