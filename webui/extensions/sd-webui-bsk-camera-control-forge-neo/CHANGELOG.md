# Changelog

## 1.3.0 - 2026-08-29

- 跟进原作者 `ComfyUI-bsk_UI_26082904` 的机位控制算法。
- 左右机位默认词由 `from right side` / `from left side` 更新为 `from right` / `from left`。
- 修正高度分档：`Y=0` 至 `Y=0.2` 为平视，任何负 Y 均进入低机位/仰视，不再错误输出 `eye-level`。
- 新增“平视权重（正平视时）”，默认 `3.0`；平视权重随正 Y 向高机位边界线性降至 `1.0`。
- 高度权重不再错误复用方位死区，轻微俯仰也能输出对应高度词。
- 与原版一致，在非空机位输出末尾保留逗号。
- 保留 v1.2.0 的 Forge Neo 任务参数直接注入，不恢复会产生闪烁或漏提交的 textarea 临时改写方案。
- 更新算法、界面与提交桥接回归测试。

## 1.2.0 - 2026-07-29

- 修复机位提示词只在正向提示词框中短暂闪烁、但没有进入实际生成请求的问题。
- 移除捕获 Generate 点击后临时改写并立即恢复 textarea 的时序链路。
- 改为直接注入 Forge Neo 的 `submit` / `submit_img2img` 参数副本；正向提示词框全程保持原值。
- 兼容 Generate 按钮、正向提示词回车提交、快捷键触发、连续生成和同任务双击。
- 增加参数布局与类型保护，避免把文生图高清放大的图库参数误判为正向提示词。
- 新增异步提交、参数副本不变、无合成 input 事件和重复挂钩防护回归测试。

## 1.1.0 - 2026-07-29

- 修复实时同步因提示词格式变化而不断追加新机位词的问题。
- 移除运行时持续改写正向提示词的旧同步链路。
- 新增独立机位提示词框；拖动、滚轮及配置变化只更新该框。
- 新增“生成时融合机位提示词”开关：提交任务时临时合并，随后恢复原正向提示词。
- 文生图与图生图分别维护自己的机位词，并兼容 Generate 按钮的程序化点击和快捷键触发路径。
- 增加连续生成、同任务双击、权重格式归一化、开关禁用和文生图/图生图隔离的 DOM 回归测试。

## 1.0.0 - 2026-07-29

- 首个 Forge Neo 移植版本。
- 保留 3D 机位可视化、相对/绝对拖动、滚轮距离和 Shift+滚轮倾斜。
- 保留方位、高度、距离、倾斜、额外提示词及动态权重算法。
- 新增文生图与图生图正向提示词的单次写入、实时同步和安全移除。
- 新增所有提示词文本的直接编辑、逐项开关、浏览器本地预设及 JSON 导入导出。
