# BSK Camera Control for Forge Neo

将 `ComfyUI-bsk_UI` 的可视化机位控制节点移植到 `sd-webui-forge-neo`。当前机位算法已跟进原作者 `ComfyUI-bsk_UI_26082904` 版本。扩展会在文生图和图生图的正向提示词框下方加入机位控制面板，不依赖额外 Python 包。

## 安装

1. 解压本压缩包。
2. 将整个 `sd-webui-bsk-camera-control-forge-neo` 文件夹放入：

   ```text
   sd-webui-forge-neo/extensions/
   ```

3. 最终目录应类似：

   ```text
   sd-webui-forge-neo/
   └─ extensions/
      └─ sd-webui-bsk-camera-control-forge-neo/
         ├─ javascript/
         │  ├─ bsk_camera_core.js
         │  └─ bsk_camera_ui.js
         ├─ style.css
         ├─ README.md
         └─ LICENSE
   ```

4. 完全重启 Forge Neo，并刷新浏览器页面。
5. 在文生图或图生图的正向提示词框下方展开“机位控制”。

## 操作

- 在可视化画布上拖动：调整左右方位与上下机位。
- 滚轮：调整镜头距离。
- `Shift + 滚轮`：调整画面倾斜。
- 方向键：微调左右和上下。
- `[` / `]`：微调距离。
- `,` / `.`：微调倾斜。
- “相对拖拽 / 绝对拖拽”：切换原插件的两种拖动方式。
- “独立机位提示词”：显示当前机位生成的提示词；拖动和修改配置只更新这个框。
- “生成时融合机位提示词”：开启后，只在本次生成任务的提交参数中把独立机位词接到正向提示词后面。
- “复制机位词”：复制独立机位提示词框的内容。

“生成时融合机位提示词”默认开启，但平时不会改写正向提示词框。若只想预览或复制机位词，可关闭此项。

## 自定义提示词

展开“自定义提示词（可直接改词）”，即可修改：

- 前、后、左、右机位词；
- 鸟瞰、高机位、平视、低机位和正下方机位词；
- 大特写、近景、中景、全身和远景词；
- 倾斜词；
- 镜头、景深、运镜、构图和风格附加词。

当前原版的左、右侧默认词分别是 `from right`、`from left`（提示词描述的是画面看到人物的方向，因此与机位坐标名称相反）。也可以直接替换成 `from right side`、`right side view` 或模型更容易识别的其它写法。每项均有单独开关，并会自动保存在当前浏览器。

“无权重模式”会输出纯标签，适合不使用 `(tag:weight)` 语法的模型。关闭后使用原插件的动态权重算法。

原插件的“方位整体权重”默认是 `10.0`，因此正面归位时会得到 `(from front:10.00)`。新版高度算法还会在完全平视时输出 `(eye-level:3.00)`；“平视权重（正平视时）”可单独调整。正 Y 的平视权重会从中心向高机位边界逐渐降至 `1.0`，负 Y 则立即进入低机位/仰视，不再与 `eye-level` 冲突。

机位输出末尾保留原版新增的逗号，便于和后续提示词连接；Forge Neo 生成参数可以正常接受这一格式。

原作者还提供了用于增强 Anima 左右机位识别的可选 LoRA：<https://modelscope.cn/models/bskhuian/Anima_Camera_Position_Control>。它不是本扩展的必需项，也未包含在压缩包中。

## 配置与预设

- 预设同时保存机位位置和提示词配置。
- “复制配置 JSON / 导入配置 JSON”可在不同浏览器、不同 Forge 安装或文生图/图生图面板间迁移配置。
- 所有配置只保存在浏览器本地，不会上传到网络。

从 v1.2.0 覆盖升级时，已有浏览器配置和预设会继续保留，避免覆盖你手动修改过的词。若希望立即采用 v1.3.0 的 `from right` / `from left` 新默认词，可在“配置与预设”中点击“恢复默认配置”，或只手动改这两项。

## 生成时融合说明

机位提示词与正向提示词分开存放。生成任务提交时，扩展会直接在 Forge Neo 的任务参数副本中组合：

```text
原正向提示词, 独立机位提示词
```

界面中的正向提示词框不会被改写，也不会出现提交时闪烁。拖动、滚轮、修改机位词配置以及连续生成都不会把旧机位词累积进正向框。Generate 按钮、正向提示词回车提交和快捷键触发均使用同一条参数融合路径。

扩展不会修改负向提示词。若从 `1.0.0` 升级，旧版本已经留在正向提示词里的重复内容属于现有文本，新版不会冒险自动删除；请手动清理一次，之后不会继续累积。

生成完成后，可在 PNG 信息的正向 Prompt 末尾确认机位提示词确实随本次任务保存。若关闭“生成时融合机位提示词”，PNG 信息中不会出现独立机位词。

## 兼容性

- 目标：`sd-webui-forge-neo`（Gradio 4 系界面）。
- 无第三方运行依赖。
- 通过 Forge/WebUI 的标准 `javascript/` 和根目录 `style.css` 自动加载机制工作。
