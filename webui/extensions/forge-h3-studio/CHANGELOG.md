# Changelog

## 0.2.2

- 修复 Forge/Gradio 全局 `footer` 隐藏样式导致取景滑杆、“重置”和“应用取景”整栏消失的问题；取景控制栏改为隔离的专用容器并强制显示。
- 同步修复任务详情底部的复用参数、下载参数和浏览输出操作可能被宿主样式隐藏的问题。

## 0.2.1

- 修复 Windows 本地图片无法直接拖入首帧/尾帧槽位；本地参考素材也可直接拖到对应槽位并自动上传、分配。
- 修复取景窗口底部滑杆被裁掉、关闭后位置丢失的问题；移动、缩放、重置和关闭都会持久化裁剪参数。
- I2V/FL2V 提交前会为没有旧裁剪数据的图片建立比例联动居中裁剪，保证工作流实际执行 `ImageCrop → ImageScale`，不再把整张图压缩到目标比例。
- 新增 Forge 后端 ComfyUI 事件中继：提交前先连接 WebSocket，任务接口持续返回当前节点、采样步、双层进度、完整错误与实时预览。
- 完成任务保留最后实时预览，为浏览器视频解码和 ComfyUI 任务历史各提供首帧缩略图兜底；临时封面不会被当作正式生成素材归档。
- 实际 Seed 会进入文件名与视频元数据；结果、任务和素材显示 Seed，支持完整参数 JSON 下载及一键复用 Seed、模型、LoRA、裁剪与采样参数。

## 0.2.0

- 生成输出自动归档到“已生成”素材库，新增视频/图片/音频大尺寸浏览器与下载入口。
- 新增 8 种原生宽高比、完整 0.2–2.0 MP 的 16:9 H3 推荐尺寸、自由取整倍数和手动宽高模式。
- 新增首尾帧比例联动取景器；支持移动、缩放和重置，并通过 ImageCrop/ImageScale 防止输入拉伸。
- 新增基于 ComfyUI WebSocket 事件的双层真实进度、当前节点、采样步和实时预览缩略图。
- 新增任务中心、运行/完成筛选、排序、队列清理、取消、耗时/ETA 与完整任务详情。
- 任务接口统一返回可直接预览的输出 URL，并记录开始时间、模型、LoRA、Seed 与节点标题。

## 0.1.0

- 新增 Forge Neo 顶级 MiniMax H3 工作台页签。
- 新增托管/外接 ComfyUI 后端、切页自动启动、状态与日志。
- 新增 T2V、I2V、FL2V、多模态参考官方 H3 工作流。
- 新增模型、文本编码器、视频/音频 VAE 与完整采样参数选择。
- 新增 H3 LoRA 加载栈、权重、排序、搜索和组合预设。
- 新增素材上传、拖放、项目保存、任务队列、结果预览和 JSON 导出。
