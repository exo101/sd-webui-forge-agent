## ✨ 新增功能

### 随机种子控制 (Random Seed Control)

为图层分离处理添加了随机种子调节功能，允许用户控制生成结果的可重复性。

#### 功能特性

1. **UI组件位置**
   - 在"高级选项"区域添加"随机种子"输入框
   - 位于"批处理大小"下方

2. **参数说明**
   - **默认值**: -1（表示随机生成）
   - **取值范围**: 任意整数（0 到 2^32-1）
   - **作用**: 设置固定种子可获得可重复的分割结果

3. **使用方式**
   - **随机模式**: 保持默认值 -1，每次处理使用不同的随机种子
   - **固定模式**: 输入具体数字（如 42、12345），每次使用相同种子获得相同结果

4. **日志反馈**
   - 处理开始时会显示设置的种子值
   - 如果设置为 -1，会显示实际生成的随机种子值
   - 便于调试和复现结果

#### 技术实现

1. **前端UI**
   ```python
   seed = gr.Number(
       label="随机种子",
       value=-1,
       precision=0,
       info="设置随机种子以控制生成结果的可重复性（-1表示随机）"
   )
   ```

2. **后端处理**
   - 在 `process_image` 函数中添加 `seed` 参数
   - 当 `seed == -1` 时，自动生成随机种子
   - 将种子参数传递给底层推理脚本 (`--seed` 参数)

3. **命令构建**
   ```python
   actual_seed = seed if seed != -1 else random.randint(0, 2**32 - 1)
   cmd = [
       sys.executable,
       script_path,
       "--srcp", input_image,
       "--resolution", str(resolution),
       "--num_inference_steps", str(num_inference_steps),
       "--seed", str(actual_seed),  # 新增参数
       "--quant_mode", "nf4"
   ]
   ```

#### 应用场景

1. **结果复现**: 当找到满意的分割效果时，记录种子值以便下次复现
2. **批量处理**: 对多张图片使用相同种子，确保处理一致性
3. **对比实验**: 使用不同种子测试分割效果的稳定性
4. **调试优化**: 固定种子排除随机因素，专注于调整其他参数

#### 注意事项

- 种子值仅影响具有随机性的处理步骤（如某些模型的初始化）
- 即使使用相同种子，不同硬件或软件版本可能产生微小差异
- 建议与分辨率、推理步数等参数一起记录，以获得最佳复现效果
