# Nano Banana

## 更新内容

### 新增 MiniMax 视频生成
- 集成 MiniMax 视频生成 API，支持文本转视频
- 支持视频生成的参数配置，包括分辨率、时长等
- 生成结果可直接在界面预览和下载

### 新增 ComfyUI 后端
- 支持将 ComfyUI 作为后端引擎进行图像生成
- 通过启动器统一管理 ComfyUI 的启动与停止
- 自动检测 ComfyUI 运行状态，实现无缝切换
- 支持 ComfyUI 工作流的一键调用

### 新增香蕉模型支持
- 集成 Pixapi API 作为图像生成引擎
- 支持 Gemini / GPT Image 系列模型
- 提供文生图、图像编辑、批量编辑、异步任务四大功能
- 自由调整图像尺寸（256~2048px 滑动条）
- 支持多模型切换与自动刷新
